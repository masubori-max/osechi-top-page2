# おせちブログ新トップページ（固定ページ30806）

このフォルダの `wordpress-fixed-page.html` と `wordpress-additional.css` を原本として管理します。WordPress管理画面を直接編集した場合も、作業終了後に同じ内容をこのフォルダへ戻してください。

## ファイル

- `wordpress-fixed-page.html`：クラシックエディターの「コード」タブへ貼り付ける本文
- `wordpress-additional.css`：外観の追加CSSへ設定するページ専用CSS
- `pre-publication-checklist.md`：公開前に毎回確認する項目
- `backup/`：2026年8月20日の変更前バックアップ

## 更新手順

1. WordPressの固定ページ30806が「下書き」であることを確認する。
2. 古い編集タブを閉じ、編集タブを1つだけ開く。
3. 変更前の本文と追加CSSを `backup/` に日付付きで保存する。
4. 商品名、人数、品数、保存方法、価格、早割、在庫、配送、キャンセル条件を販売元で再確認する。
5. `wordpress-fixed-page.html` を修正し、要約・比較表・商品詳細・最終比較の表記を一致させる。
6. 外部購入リンクには `target="_blank"` と `rel="nofollow sponsored noopener"` を設定する。
7. `wordpress-additional.css` は `.osechi-page` または `.page-id-30806` 配下に限定する。
8. HTMLとCSSをWordPressへ反映して下書き保存する。
9. 保存後に管理画面を再読込し、本文がサーバー側に残っていることを確認する。
10. PC・タブレット・スマートフォンのプレビューと全CTAの遷移先を確認する。

## 年次更新

- 年、最終確認日、商品画像、人数、品数、保存方法、CTA文言、リンク先を商品単位で更新します。
- 価格や早割期限は変動しやすいため、原則として固定表示せず販売先での確認を促します。
- 「No.1」「一番人気」などの表現は、販売元が調査主体・期間・対象を明示している場合だけ使用します。
